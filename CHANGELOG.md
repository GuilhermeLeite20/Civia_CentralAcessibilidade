# Histórico de versões

O projeto segue uma forma simplificada de versionamento semântico.

## [0.1.0] - Versão inicial acadêmica

### Incluído
- Central de acessibilidade em Windows Forms
- Cadastro de barreiras urbanas e pontos de apoio
- Busca, filtros, detalhes e atualização de status
- Indicadores de acompanhamento
- Persistência local em JSON e exportação CSV
- Dados fictícios opcionais de demonstração
- Documentação e modelo de Pull Request

> A publicação da tag `v0.1.0` no GitHub deve ser realizada após revisão e merge do PR.
